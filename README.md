## 03 / SELECTED PROJECTS

### 🏥 VANI — Intelligent Post-Discharge Care

An AI-powered healthcare companion designed to make post-hospitalization care more accessible through medicine reminders, voice interaction, prescription OCR and intelligent assistance.

**Tech:** React Native · Expo · TypeScript · Firebase · AI · OCR · Cloud

### 🏛️ TIKO — Interactive Heritage Learning

An immersive learning experience exploring Indian heritage and culture through interactive technologies, gamification and AR/VR concepts.

**Tech:** Flutter · AI/ML · AR/VR · Interactive Learning

### 👁️ Smart AI Attendance & Surveillance

A real-time computer vision-based attendance automation system using facial recognition and object detection.

**Tech:** Python · OpenCV · YOLO · Firebase · Flask

### 🖐️ Gesture Controlled Cursor

A computer vision project that transforms hand gestures into mouse movements and system interactions.

**Tech:** Python · OpenCV · MediaPipe

[Explore Repository →](https://github.com/PyRaghaw/Gesture-Control-System)

### 🎓 ScholarConnect — AI Scholarship Platform

An AI-powered scholarship discovery and recommendation concept with document processing and OCR integration.

**Tech:** Python · Flask · FastAPI · Tesseract OCR
